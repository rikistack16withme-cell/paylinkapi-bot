# 🚀 Quick Start Guide

Welcome to the PaylinkApi developer documentation.

## Overview
PaylinkApi provides unified payment infrastructure bridging **Bakong KHQR** and **ABA PayWay Gateway** into a standardized developer experience.

## Steps
1. Select your target payment rails: Bakong, ABA, or Dual Bundle.
2. Submit your merchant configuration parameters in the bot:
   - **Bakong KHQR**: Enter your custom store/merchant name directly inside the bot.
   - **ABA PayWay**: Set up your store name in the **ABA Merchant App**, generate your payment links, and copy them into the bot.
3. Obtain your sandbox test credentials for staging development.
4. Integrate transaction webhooks for real-time order fulfillment.

> ℹ️ *Phase 1 Notice: Full live sandbox endpoints and credential verification will be activated in Phase 2.*
